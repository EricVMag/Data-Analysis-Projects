# Data Analysis Projects

A collection of data analysis and data science projects exploring real-world business problems through data.

Projects in this repository include coursework, independent analyses, and personal projects. They demonstrate skills in **data cleaning, exploratory data analysis, statistical analysis, data visualization, predictive modeling, and machine learning** using tools such as Python, SQL, and related data analytics libraries.

## Projects

### Employee Turnover Prediction

Analysis of employee data to identify factors associated with employee turnover and develop a machine learning model to predict whether an employee is likely to leave the company.

**Key skills:** Exploratory Data Analysis (EDA), data visualization, feature engineering, Random Forest, XGBoost, model evaluation, and model interpretation.
